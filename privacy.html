개인정보처리방침

최종 수정일: 2026년 6월 25일

1. 수집하는 정보

유튜브 AI 도우미는 사용자가 직접 입력한 텍스트 또는 음성(변환된 텍스트) 요청만 처리합니다. 이름, 이메일, 개인 식별 정보는 수집하지 않습니다.

2. 정보 사용 방법

입력된 요청은 AI 분석을 위해 Cloudflare Worker를 통해 Anthropic Claude API로 전송됩니다. 요청은 즉시 처리되며 저장되지 않습니다.

3. 제3자 공유

사용자 요청은 Anthropic(Claude AI 제공사)의 API 서버로 전송됩니다. Anthropic의 개인정보처리방침은 anthropic.com/privacy에서 확인하실 수 있습니다.

4. 데이터 보관

이 확장 프로그램은 사용자의 요청을 서버에 저장하지 않습니다. 글씨 크기, 강조색, 소리로 읽기, 자동 클릭 등 보기 설정 값만 브라우저 로컬 스토리지(chrome.storage.local)에 저장됩니다. "소리로 읽기"는 브라우저 내장 음성 합성(speechSynthesis)을 쓰며, 컴퓨터에 설치된 음성을 우선 사용합니다. 설치된 음성이 없으면 브라우저가 제공하는 온라인 음성(예: Google 음성)이 쓰일 수 있고, 이 경우 읽어 주는 안내 문장이 해당 음성 서비스로 전송될 수 있습니다.
